デュエルスキン

ドット絵を一新

デュエル中のカードはカードの色の平らな枠に大きなイラストが入る形になり、ひと目で読みやすくなりました。ドットのフィルターはより細かくなって画面全体にかかり、文字や国旗はくっきりしたままです。デッキ編集のカードはドット化されなくなり、カードの印はドットの星とバツになりました。

デュエルスキン

キャラクター選択も全スキン対応

キャラクター選択画面がデュエルスキンに合わせて変わるようになりました：ガンメタルと金のデュエルディスク、もやのかかった闇の世界、クリーン・トーナメント、千年石版、海馬ホログラム、そしてドット絵（上記）。コスメティックで変更できます。

レリック

影のレリックと黒魔術

呪いのレリックは影のレリックという名前になりました。ボスの呪いと混同しないためで、それ以外は何も変わりません。

魔法の聖域新しい影のレリック。自分は相手ターン中に魔法カードを発動できる。デメリット：自分は魔法カードをセットしてからでないと発動できない。セットした魔法カードはセットしたターンには発動できない。

不滅の黒魔術融合レリック：魔術師の杖、魔術師の絆、師匠と弟子、黒き混沌の儀。自分フィールドの魔法使い族モンスターの攻撃力は600アップする。魔法使い族モンスターを通常召喚した場合に発動できる。デッキから「ブラック・マジシャン」モンスター1体を特殊召喚し、「ブラック・マジシャン」のカード名が記されたカード1枚をデッキから手札に加える。自分フィールドの「ブラック・マジシャン」モンスターが破壊され墓地へ送られた場合に発動する。「ブラック・マジシャン」のカード名が記されたモンスター1体をデッキまたはエクストラデッキから召喚条件を無視して特殊召喚する。

黒衣の大賢者常に「ブラック・マジシャン」カードとして扱うようになりました（デーモンの召喚が「デーモン」として扱われるのと同じです）。すべてのブラック・マジシャンのレリックで数えられます。

武藤遊戯専用のパック武藤遊戯は闇遊戯とパックを共有しなくなりました。収録89枚：暗黒騎士ガイア、カオス・ソルジャー、ビッグ・シールド・ガードナー、クリボー、磁石の戦士、ガジェット、アルカナ ナイト、LVモンスター、エクゾディア、そして豊富なドローと除去。

ランダマイザー

ランダム化カードを再構築

レインボーカードは実在のカードの構成をもとに作られるようになり、効果やカードの種類、数値が実在のカードと同じくらいの頻度で出ます。カテゴリ効果を持つカードは名前にカテゴリ名が入り、テキストはより明確に、矛盾する効果はなくなり、手札から自身をタダで出す効果にはコストか条件が必要になりました。

Windowsアプリ

アプリが自動で更新

このバージョンから、Windowsアプリが自分でアップデートをインストールします。古いバージョンをお使いの場合はメインメニューにお知らせが出ます：インストーラーをもう一度ダウンロードしてください。セーブデータはそのまま残ります。

「ドキュメント」フォルダーがブロックされていても別のフォルダーに保存され、ランシートの画像をコピーは画像を保存せずにコピーします。

変更点

  • 🌈ストラクチャーデッキは購入できるときだけショップに並び、見逃さないよう虹色に光ります。
  • 🔎パックの詳細で、種族・属性・カテゴリがリンクになりました。タップすると、そのパックの該当カードだけを表示します。
  • 🃏相手のデッキの表示がパック表示と同じ幅になり、一度に多くのカードが見られます。
  • ⚡効果を必ず発動する場合、✕がグレー表示されなくなりました。押すと効果が発動します。
  • 🈶キャラクター名が公式の日本語・韓国語・中国語の名前になりました。
  • 🤖CPUをゲーム内のすべてのデッキで見直しました。アマゾネスの弩弓隊、カタパルト・タートル、あまのじゃくの呪い、女忍者ヤエなど、これまで使わなかった数十枚のカードを使うようになり、装備や和睦の使者の判断も良くなりました。
  • ↕️デッキの上のカードを並べ替えるとき（大王目玉など）、終わったら✓を押すよう案内が出ます。
