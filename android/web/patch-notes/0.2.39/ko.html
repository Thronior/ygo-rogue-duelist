유물

그림자 유물과 흑마술

저주받은 유물은 이제 그림자 유물이라고 부릅니다. 보스의 저주와 헷갈리지 않게 하기 위해서이며, 그 밖에는 아무것도 바뀌지 않습니다.

마법의 성역새 그림자 유물. 자신은 상대 턴에 마법 카드를 발동할 수 있다. 단점: 자신은 마법 카드를 먼저 세트하지 않으면 발동할 수 없다. 세트한 마법 카드는 세트한 턴에는 발동할 수 없다.

불멸의 흑마술합성 유물: 마법사의 지팡이, 마술사의 인연, 스승과 제자, 검은 혼돈의 의식. 자신 필드의 마법사족 몬스터의 공격력은 600 올린다. 마법사족 몬스터를 일반 소환했을 경우에 발동할 수 있다. 덱에서 "블랙 매지션" 몬스터 1장을 특수 소환하고, "블랙 매지션"의 카드명이 쓰여진 카드 1장을 덱에서 패에 넣는다. 자신 필드의 "블랙 매지션" 몬스터가 파괴되어 묘지로 보내졌을 경우에 발동한다. "블랙 매지션"의 카드명이 쓰여진 몬스터 1장을 덱 또는 엑스트라 덱에서 소환 조건을 무시하고 특수 소환한다.

검은 옷의 대현자이제 항상 "블랙 매지션" 카드로 취급됩니다(데몬 소환이 "데몬"으로 취급되는 것처럼). 모든 블랙 매지션 유물이 이 카드를 셉니다.

유희 전용 팩유희는 더 이상 어둠의 유희와 팩을 공유하지 않습니다. 89장 구성: 암흑 기사 가이아, 카오스 솔저, 빅 실드 가드너, 크리보, 마그넷 워리어, 가제트, 아르카나 나이트, LV 몬스터, 엑조디아, 그리고 많은 드로우와 제거 카드.

랜더마이저

무작위 카드 재구성

무지개 카드는 이제 실제 카드의 구성을 바탕으로 만들어져, 효과와 카드 종류, 수치가 실제 카드만큼 자주 나옵니다. 카테고리 효과가 있는 카드는 이름에 카테고리명이 붙고, 문장이 더 명확해졌으며, 모순되는 효과는 사라졌고, 패에서 공짜로 자신을 소환하는 효과에는 코스트나 조건이 필요합니다.

Windows 앱

앱이 스스로 업데이트

이번 버전부터 Windows 앱이 업데이트를 스스로 설치합니다. 이전 버전을 쓰고 있다면 메인 메뉴에 안내가 나옵니다: 설치 프로그램을 한 번 더 내려받으세요. 저장 데이터는 그대로 유지됩니다.

문서 폴더가 막혀 있으면 두 번째 폴더에 저장되며, 런 시트의 이미지 복사는 이미지를 저장하지 않고 복사합니다.

변경 사항

  • 🌈스타터 덱은 살 수 있을 때만 상점에 나타나며, 놓치지 않도록 무지갯빛으로 빛납니다.
  • 🔎팩 상세 정보에서 종족, 속성, 카테고리가 링크가 되었습니다. 하나를 누르면 그 팩에서 해당하는 카드만 보여 줍니다.
  • 🃏상대 덱 보기가 팩 보기만큼 넓어져 한 번에 더 많은 카드를 보여 줍니다.
  • ⚡효과를 반드시 발동해야 할 때 ✕가 더 이상 회색으로 비활성화되지 않습니다. 누르면 효과가 발동합니다.
  • 🈶캐릭터 이름에 공식 일본어·한국어·중국어 이름을 사용합니다.
  • 🤖CPU를 게임 속 모든 덱으로 점검했습니다. 아마조네스의 궁수대, 중강갑 거북, 심술꾸러기의 저주, 여첩자 야에 등 예전에 무시하던 카드 수십 장을 이제 사용하며, 장착과 화목의 사자 판단도 더 좋아졌습니다.
  • ↕️덱 위의 카드 순서를 정할 때(빅 아이 등) 끝나면 ✓를 누르라는 안내가 나옵니다.

  • 🔤런 시트에 캐릭터 이름이 설정한 언어로 표시됩니다.
