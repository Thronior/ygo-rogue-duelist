새 카드

식물족 서포트

식물족 카드 10장론 파이어 블로섬, 기가플랜트, 춘희 티타니얼, 세계수 등이 야생의 땅에 추가됩니다. 사마준의 새 변형 우거진 정원이 곤충 진화을 대체합니다.

난이도

쉬움 모드

런을 시작할 때 난이도를 고릅니다. 쉬움: 보스 저주 없음, 승리할 때마다 LP 2,000 회복, 시작 시 제거 카드 추가, 그림자 유물은 건너뛸 수 있습니다. 쉬움 모드 런은 업적이나 해금에 포함되지 않습니다.

쉬움일반
유물

새 유물과 유물 도구

식물족 유물광합성은 식물족만큼 회복하고, 봄의 성장은 매 턴 식물족을 키우며, 폴리네이터는 모스 토큰을 불러옵니다.

운명의 모래시계아직 없는 위저 보드 조각을 먼저 제시합니다.

✕

유물 제외상점에서 유물의 ✕를 탭하면 10코인으로 제외합니다. 이번 런에는 다시 나오지 않습니다. 태그에서도 됩니다.

듀얼 중에 1번이 유물들이 발동하면 일러스트가 크게 표시되고, 유물 바의 아이콘은 듀얼이 끝날 때까지 회색이 됩니다.

찾아낼 새 합성 유물 3개도 있습니다.

얼티밋 컬렉터

턴 제한 시간과 일시 정지

플레이할 때마다 제한 시간이 15초 늘어납니다. 시간이 다 되면 매치가 아니라 그 듀얼만 집니다. 1분 미만이면 타이머가 빨갛게 됩니다. 일시 정지를 요청할 수 있습니다(매치당 2회). 보상 화면에서 내 덱을 보고, 카드에 ★ / ✕ 표시를 할 수 있습니다.

드래프트

더 많은 팩

이제 픽마다 팩 3개를 열고, 매 루프는 서로 다른 세트 3개의 팩 3개로 시작합니다.

통계

CPU 통계

각 CPU의 플레이어 상대 승패를 Tier별로 보여 주는 새 탭. CPU를 탭하면 듀얼리스트별 전적을 볼 수 있습니다. 익명: 어떤 플레이어도 추적하지 않습니다.

설정

단축키와 CPU 속도

설정 › 단축키: 모든 단축키를 다시 지정할 수 있습니다. CPU 행동 지연: CPU를 행동마다 0~1,000ms 느리게 합니다.

덱 구축

카드를 더 빠르게 찾기

검색이 입력하는 대로 갱신됩니다. 분할 덱 화면에 엑스트라 덱 칸이 생겼습니다. 컬렉션 › 팩에서 드로우, 장착 마법, 몬스터 종족으로 필터할 수 있습니다.

새 신 카드 슬리브

조이의 팩

플레이어 1만 명!

플레이어 설문

감사합니다! 짧은 설문이 한 번 나타납니다: 좋아하는 듀얼리스트, 상대, 유물, 그리고 앞으로 보고 싶은 것. 종 아이콘에서 다시 찾을 수 있습니다.

변경 사항

  • 🎲캐릭터 선택의 주사위 버튼이 무작위 듀얼리스트를 고릅니다.
  • 🏆타이틀 화면에 달성한 업적 / 전체가 표시되고, 퍼센트는 바 안에 나옵니다.
  • 🧠CPU: Tier 4와 컬렉터 덱에서 약 30장의 카드를 더 쓰고, 전체 제거를 총 공격력으로 판단하며, 왕호 왕후, 노블 드 느와르, 마도전사 브레이커를 더 잘 다룹니다.
  • 🔀랜더마이저 카드가 더 다양해지고, 실제 효과를 그대로 베낀 것이 줄었습니다.
  • 🔍융합과 장착 필터가 모든 융합 몬스터와 장착 마법을 찾습니다.
  • 🪦묘지도 덱처럼 열려, 첫 탭에 자세히 보기가 표시됩니다.
  • ⚙️설정의 ✕를 누르면 원래 화면으로 돌아갑니다. Esc로 어떤 창이든 닫을 수 있습니다.
  • ❓융합 힌트가 합성 유물에 필요한 조각 수를 셉니다.
  • 🐧Linux 앱: 사운드 코덱이 없어도 게임이 멈추지 않고, 설치할 패키지를 알려 줍니다.

수정 사항

  • 🧪체력 증강제 슈퍼 Z가 텅 빈 성배의 추가 데미지도 계산합니다.
  • 1️⃣싱글턴 서약을 얻으면 덱에서 여분의 사본을 제거합니다.
  • 🛡️충성이 뒷면 표시 몬스터도 지킵니다(태그의 두 플레이어 모두).
  • 👥태그: 보스 저주가 더 이상 중첩되지 않습니다.
  • ⛓️체인: 가끔에서도 백병전을 물어봅니다.
  • 🪙코인 보상 팝업을 끄면 듀얼 중 +코인 팝업도 숨겨집니다.
  • 💾덱 편집: 탭이 더 이상 먹통이 되지 않고, 기기에 저장할 수 없으면 알려 줍니다.
  • 🧊애니메이션이 멈춰도 듀얼이 멈추지 않습니다.
  • ✋랜더마이저 카드: 패에서 지불하는 코스트가 작동하고, 문구가 더 명확해졌습니다.
  • 🚩행동 신고: 검은 펜던트, 관통 데미지, 유언장, 제너럴 데몬.
  • 🐧Linux 앱: 소리가 더 이상 일찍 끊기지 않습니다.
