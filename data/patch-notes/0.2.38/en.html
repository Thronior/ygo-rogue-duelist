YGO Rogue Duelist

Update 0.2.38

Important fixes

Tag rooms and Tag progress

Tag rooms could expire while you were still in them, for example while editing your deck or with the game in a background tab. A room now stays as long as anyone is in it.

Tag progress (wins, Challenge Levels, sleeves) is saved right away, even if you close the game without pressing Exit.

The deck editor error some players got in 0.2.37 is fixed.

New

Character settings

Tap the on a character, or open Settings › Character in a duel.

Saved card marks ★✕ start every new run with that character, also in Tag. Pick cards from your whole collection or one pack.

Save marks from runs keeps the marks you set while playing.

New opponent

PaniK

PaniK joins the opponents with a Book of Life / Vampire deck at Tier 3 and a new Endless deck.

CPU opponents

We compared 37,000 player turns with the CPU's choices. It now keeps Tributes when a Level 4 attack hits harder, uses Raigeki and Dark Hole to open lethal, snipes with Snipe Hunter, picks safer lethal lines into face-down cards and counts double attackers.

Balance

Relic odds and runs

Relic odds

  • ◆Archetype relics (Amazoness Standard, Toon World…) appear once you own one of their cards, and much more often for every one in your Deck.
  • ◆Relics for specific cards (Gate Calling, Black Chaos Rite…) are rarer while you don't own those cards.
  • ◆Duelist's Catalogue is no longer rare. Owning an Attribute relic no longer lowers the others.
  • ◆★ marks count only for cards you own that aren't in your Deck.

Runs

  • ◆From Challenge LVL 3, Random Packs and Absolute Random appear only once that character has beaten that level.
  • ◆The first duel's decks now hold Dust Tornado, De-Spell and Remove Trap, so they can drop as rewards.
Languages

Translated everywhere

Every card's option buttons, every hover text, the run sheet, pack names and descriptions, character names and summon labels are now in all 8 languages. Some options showed the wrong official wording (like Kunai with Chain) and are fixed.

Changes

  • ⌛Final Countdown shows the ⌛ 3 turns left under the turn counter, wins with a new flame finale, and pays at least 300 coins with no slow duel penalty.
  • 🗂️The run sheet groups copies of the same card, and a long curse list wraps instead of spilling out.
  • 🌈Randomized cards get a faint rainbow over their effect text.
  • 🔤The Spirit Message cards show the TCG art, so the letters spell FINAL.
  • 🤝The Trade 0/2 button in the Tag deck builder stands out.
  • ⏎Enter in a search box runs the search.
  • 🃏The card window's buttons fit narrow phones; the new-run window says "Choose a save slot".

Fixes

  • 🐉Dragon Lord's Decree and similar relics now reach your Tag partner's cards.
  • 🛡️The CPU no longer destroys its own equips with Frontier Wiseman.
  • 💤The CPU no longer attacks into Dreamsprite when the attack would be moved onto a stronger monster.
  • ⏱️No false "CPU made no move" report after returning to the game.
  • 🌀Maharaghi's reveal no longer names the last card on the chain.
  • 🎲Randomized cards' buttons say what they do instead of "Resolve effect".
  • 📋Challenge LVL 1 no longer says "Includes all previous modifiers".
