# 0.1.30

- Fixed stale-choice errors and duplicate inputs in tag duels.
- Added Flag behaviour to duel Options: describe a CPU mistake and send its replay automatically.
- Improved CPU decisions around piercing damage, tributes, and saving defensive traps, with replay-based improvements tested against existing enemy decks.
- Tag final duels start both players at 8,000 LP, with no relics, an alternating relic draft, or all relics. Different votes use a short random selection animation.
- Added clearer excavation and effect feedback, including Magical Merchant and Reasoning.
- Moved tag trading to the deck editor and fixed received-card acknowledgement. Room codes remain visible throughout tag mode.
- Tag shops offer three featured cards from Player A's chosen reward and two from Player B's. Removed vague name-based shop categories.
- Made the mobile menu draggable with smoother movement.
- Improved screen-edge spacing and notch handling. Kept confirmations inside existing effect-selection windows.
- Replaced the boss music with a calmer track.

Android and webapp only. No Windows desktop or Xcode/iOS export.
