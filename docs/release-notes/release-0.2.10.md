**YGO Rogue Duelist — Update 0.2.10**

**Cloud saves**
- Cloud save now uses a private 10-character code. Keep it somewhere safe and enter it on any device to restore your progress. Saves are encrypted on your device, so only someone with the code can read them.
- New players are asked once whether to turn cloud save on. Old cloud backups move to a code automatically, shown once.

**New**
- Collection → Character Stats: wins and losses for every character at each challenge level. Dying after a loop counts as a win.
- 6 new cursed relics: Blood Toll (pay with LP instead of coins), Berserker's Pact, Shield Bash, Reversed Remedy, Conscription Drum and Shared Hex.
- Silver Chalice is now an Overflow Chalice: healing past your max LP after a duel turns into 3 coins per 100 LP.
- Jester's Coin is a plain toss: heads +300, tails −300. All coin tosses now appear in a window like dice.
- A "You lose" voice line plays when you lose a duel.

**Changes**
- Settings redesigned into sections.
- The Tag shop now looks and feels like the solo shop.
- Opponent reveal: tap the hidden portrait itself, then confirm.
- Veteran's Might boosts every Level 4 monster.
- Name Changer's archetype also covers the Extra Deck and banished cards.
- Hand stats now account for your own curses.
- Smaller hand-limit shake, yellow frames stay visible on burning zones, and a gradient behind card rewards and coin payouts.
- Kunai with Chain only opens a response window on attacks, summons and activations.

**CPU**
- Uses revival cards (Call of the Haunted, etc.) to survive lethal attacks.
- Picks narrow removal over a wipe against a single monster.
- Flips Morphing Jar #2 after attacking, and tracks who owns each card.
- Plays 40+ opponent cards it used to ignore.
