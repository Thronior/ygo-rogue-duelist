# Update 0.2.19

## New
- **Boss announcement voice lines:** every boss is announced when revealed, and rerolling plays the new boss's line. Bosses also show a deck name.
- **Duel 9:** the final boss now steps out of the dark. You can still reroll them.
- **Coin rewards:** each reward pops up behind the window with a quiet coin sound. Bigger rewards are bigger and stay longer.
- **Duel Looks:** five new board styles in Settings, Display. The default is unchanged.
- **No Pain No Gain:** new relic. Earn 5 coins every time you lose LP, paid after each victory.

## Relics and packs
- **Reckless Spear:** monsters can attack directly but lose 1000 ATK.
- **Trapbound Idol:** Trap Monsters can't be destroyed by battle. Each Spell Card costs 300 LP.
- **Exodia:** pieces, Necross and Contract left the Arkana, Rebecca and Shadi packs.

## Quality of life
- Bigger hand in portrait, using the spare space.
- Tap a card to see what's changing it.
- 14 more relics flash when they trigger.
- Personal bests on the reward screen, and loading tips.
- Deck Card Size setting: 3 to 10 cards per row.
- New Game is now New Run, and Continue only shows with a save.
- A newly unlocked Challenge Level is selected for you.
- 4 new run card frames, opponent portraits with duel numbers, and past run cards in Run History.
- Menus share one header and button style.

## CPU
- Kunai with Chain now stops attacks when declared.
- Rates ? ATK/DEF monsters in hand properly.
