**YGO Rogue Duelist v0.2.45 (hotfix)**

## Saving on the web is fixed
- Web, Windows app and Linux app: since 0.2.44, progress could go back after reloading the game, and Restore from code said "This backup is empty." Both are fixed. Progress you made in 0.2.44 comes back automatically the first time you start this version, and cloud save codes restore again.

## CPU fixes
- The CPU no longer freezes when it plays Tribe-Infecting Virus against monsters that have every Type.
- The CPU no longer uses Book of Moon when it has no monster left that can attack.
- The CPU no longer summons Archfiend General without Pandemonium.
- The CPU no longer uses Brain Control on a monster that Spells cannot target.
- The CPU answers Magic Drain better, and no longer attacks a stronger defender with Hyper Hammerhead when its LP are low.

## Other fixes
- Boss Monster now fully stops Spells and Traps such as Snatch Steal.
- Scapegoat Pasture and other relic tokens keep their stats under Iron Silence.
- Pyramid of Lightning and Toon Premiere work for both players in Draft Duels.
- Chain sometimes: Shadow Spell is now offered before the opponent's Battle Phase, so it can stop an attack.
- Windows app: its folders are now called "Yu-Gi-Oh! Rogue Duelist" instead of "Shadow Run" (in Documents and the app data). They are moved automatically, saves included.
- The survey's first question now asks "Where are you from?".
