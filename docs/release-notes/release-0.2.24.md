**YGO Rogue Duelist v0.2.24**

## New run end screen
Your run card now takes centre stage. After a win, the shiny **Challenge level** button starts a new run with the same character at the next level, straight from the end screen. Looping is still there, just quieter. Unlocking a character's second variant now gets its own big reveal.

## Type and Attribute icons
Declaring a Type or an Attribute now uses icons, with the Attribute Orbs for Attributes. Types that no card in the game has are hidden.

## Time Wizard spins a wheel
Time Wizard's coin toss is now a roulette wheel: land on a tower or a skull.

## New relic art
19 relics get new artwork, including Chaos Orb, Granite Heart, Battle Proficiency and Let's Go Gambling.

## Less battery and heat
Background animations (duel particles, glows, the title screen) now run on a shared, slower clock. They look the same but use far less power, so phones stay cooler.

## New Tier 3 decks
Weevil Underwood (Insects), Odion (Serket and Tiki traps) and Marik Ishtar (Gravekeeper's) bring new Tier 3 decks.

## New & Changes
- **Split Deck Editor:** a new Display setting splits the deck editor from 10 cards per row.
- **Copycat** now starts against Tier 1 opponents instead of the tutorial opponent.
- **Auto-Placement** no longer flashes the zone highlight when it places a card for you.
- **Divine Gambler** is the new name of the fused relic Second Coin Toss.
- **Phones:** the floating Chain button moves below a prompt instead of covering its buttons.

## Smarter CPU
- Brain Control takes your strongest monster and Tributes it for a Monarch, and Monarchs now use their summon effects.
- Plays Gravekeeper's cards, including Necrovalley, Rite of Spirit and Gravekeeper's Chief.
- Levels up Ultimate Insect, and only Sets Mystical Beast of Serket with a Temple of the Kings.
- No longer counts Tokens that can't be Tributed, like Sheep Tokens, as Tribute fodder.
- Reads a face-down monster's DEF correctly under Mirror Stats.

## Fixes
- **Karate Man** now doubles its original ATK, so relic, Field Spell and Equip boosts stay.
- Prompts that ask for one Type or Attribute no longer let you tick several.
