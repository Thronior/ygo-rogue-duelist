**YGO Rogue Duelist v0.2.20**

## New
- **Relic Fusions:** some relics react to each other. Find out which yourself.
- **Run progress:** the run card's VICTORIES strip now shows on the opponent and shop screens, solo and Tag.
- **Device Stats:** new Opponents tab with your wins and losses against each opponent.
- **Global Stats:** win rates for every relic and cursed relic. Character Stats list the most played first.
- **Tag:** reopening Tag after a reload or restart puts you straight back into your run.
- **Stuck duels:** if the CPU stops moving for 10 seconds, the game offers to flag it.
- A notice now shows if a card effect runs into an error.
- A × button resets all card filters in one tap.

## Changes
- **Tristan** starts with Gagagigo, Giga Gagagigo and Gogiga Gagagigo.
- **Chain Sometimes:** Numinous Healer always asks. Fairy Box and Half or Nothing only ask when an attack is declared.
- **Blood Toll** prices show an LP icon instead of coins.
- **Tag shop:** both players' guaranteed packs are offered.
- Vibration also triggers when you lose LP and on rare pulls.
- Coin reward text scales with the amount.
- The next opponent's background and cards load ahead of time.
- The portrait hand is back to its old size. Boss deck names are no longer shown.

## Duel Looks
- Every look now shows zone highlights and greyed-out phase buttons again.

## CPU
- Juragedo no longer boosts Defense Position monsters.
- Mystic Tomato and similar monsters attack into losing fights when they have a target to search.
- Plays A Hero Emerges and Snatch Steal more carefully.

## Fixes
- Fusion Time now actually Fusion Summons.
- Tag: reward spins, opponent reveals and deck peeks no longer fail with "State changed" when your teammate acts first.
- You can no longer start a new run in two slots at once.
