**YGO Rogue Duelist — Update 0.1.99**

**CPU**
- Improved CPU decisions for Sanctuary in the Sky, Mokey Mokey, Ojama, Archfiends, Ninjas, and LV monsters.
- The CPU now accounts for Agent of Force - Mars's Sanctuary bonus, Command Knight's ATK aura, and Reversed Might's standard and amplified stat-swap rules.
- Improved Blue-Eyes support through Kaibaman and The Dark - Hex-Sealed Fusion, plus target choices for Riryoku and other multi-card effects.
- Removed the low-deck defensive stall behavior so the CPU keeps pursuing lethal instead of waiting for the opponent to deck out.
