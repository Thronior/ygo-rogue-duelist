**YGO Rogue Duelist — Update 0.2.0**

**Duel & CPU**
- Improved deck-aware CPU decisions for Sanctuary in the Sky, Blue-Eyes, Magnet Warriors, Ojamas, Archfiends, Ninjas, and LV monsters.
- Improved the CPU’s use of key effects, multi-card choices, and combo pieces, including Megarock Dragon and the Egyptian God Cards.
- The CPU accounts for Sanctuary’s boost to Agent of Force - Mars, Command Knight’s ATK bonus, and Reversed Might’s normal and amplified effects.
- Removed defensive deck-out stalling so the CPU keeps pursuing a win.

**Opponents & Decks**
- Added Arcana Knights for Siegfried von Schroeder (T3), Archfiends for Darkbishop Archfiend (T3), Blue-Eyes for Kisara (T1), and Horus for Mokuba (T2).
- Added Monarchs for Thestalos (T3), Ninjas for Lady Ninja Yae (T2), Spell Counters for Breaker (T2), Spirits for Cecelia Pegasus (T4), and XYZ Machines for Johnson (T2).
- Moved Yugi Muto’s existing T1–T3 decks to Shimon and gave Yugi the Level Friends deck as a new T3 deck.

**Relics & Curses**
- Fixed Demonic Pact so it recovers half of Archfiend costs that Pandemonium prevents, with the relic description updated to match.
- Updated the amplified Thin Ranks description to correctly state that it removes three opening cards.

**Shop**
- Improved shop touch handling so item selection, long-press details, and other controls no longer interfere with each other.
- Repositioned and cropped Solomon behind the shop controls, hid him in portrait mode, and adjusted his placement for landscape layouts.
