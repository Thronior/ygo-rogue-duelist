**YGO Rogue Duelist v0.2.33**

## Play on Windows
The game now has a Windows app. On the web version, open **Download the app** and pick **Download for Windows**.
- Installs with a Start menu shortcut, and a desktop shortcut if you want one.
- **Updates itself:** new versions download in the background and apply when you restart the game.
- If Windows warns about an unknown publisher, choose **More info › Run anyway**.

## Related Cards
The card window has a **Related Cards** tab: cards that mention this card, and cards this card mentions. Archetype names count too. In the deck editor, use − / + to take related cards you own out of your Deck or put them in.

## New reward categories
- **Monster Removal** (new): cards that destroy, banish or bounce monsters.
- **Spell & Trap Removal** (new): cards that clear Spells and Traps. Cards that hit both are in both.
- **Staple Traps:** the old "Hole Traps" category.
- The next opponent screen now favours reward categories that fit your Deck, and removal categories come up more often. In Tag, both players' Decks count.

## Changes
- **Android:** if an update fails to install, the message now explains how to allow it: Settings › Apps › Yu-Gi-Oh: Rogue Duelist › Install unknown apps.
- **Online servers:** global stats upload less often and old Draft Duel rooms are cleared out, so the servers stay under their daily limit more easily.
