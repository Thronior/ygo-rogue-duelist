# v0.1.88

This update adds 18 relics, expands the shop, and improves character variants and relic feedback.

- **New relics:** This Life Is Mine, Boss Monster, Sword and Shield, Broken Limiter, Let's Go Gambling, Terraforming, Good Spirits, Dark Scorpion Squad, Gravekeeper's Union, Amazoness Hunters, Harpies of a Feather, Demonic Pact, All for One Terrorking, Ojama Gang, Tribute Free, Fusion Time, Level One, and LEVEL UP.
- **Relic updates:** Level Bonus now gives LV monsters 400 ATK. Razor Ledger checks the current minimum deck size. Level One adds only a Level 1–4 LV monster. Relic descriptions and prices have been corrected, including the requested 10-coin reductions.
- **Shop:** Relics can be sold for half their original price. Owning an attribute-changing relic makes competing attribute-changing relics and elemental orbs less likely to appear. Booster descriptions now identify archetypes when present.
- **Character variants:** Ryou Bakura's second variant, Fortune's Favorite, starts with a random relic that adds archetype cards to shop stock.
- **Other fixes:** Solomon's Level -1 shop portrait layout is corrected, menu artwork loads independently of artwork bundles, and failed asset retries now bypass a stale cached response.
