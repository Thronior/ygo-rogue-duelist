v0.1.75

- Added an optional startup preload for music, extra artwork and background videos. Sound effects still preload every time, and the choice can be changed in Settings.
- Improved download retries and timeout handling. Failed optional artwork no longer prevents startup, and interrupted offline downloads retain completed files for retry.
- Improved Magical Scientist's CPU decisions: prioritize a usable removal Fusion against a worthwhile opposing threat, and conserve LP otherwise.
- Made Chain sometimes the default and added relevant activation prompts during the opponent's End Phase.
- Various minor UI tweaks.
- Reduced music download size by 22% (about 21 MiB).
