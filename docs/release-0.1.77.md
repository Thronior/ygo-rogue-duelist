# v0.1.77

- Reduced background server activity and unnecessary saves to help keep online features within Cloudflare's free limits, while keeping gameplay responsive.
- Added optional cloud saves in Settings, off by default. Enabled backups begin after an unlock and save progress after duels. Local saves still work as before.
- Improved behaviour-report retry handling so failed submissions stay saved for retry.
- Added mouse-hover descriptions for booster packs and curses.
- Fixed coin-toss and dice results appearing before their animations finish.
- Updated Solomon Muto, Copycat and Dueling Engine portraits.
- Various minor UI tweaks.
